# Python Portfolio

A collection of Python projects built to practice programming,
problem-solving, and software development.

## Projects

### Mad Libs Game
An interactive word game that generates funny stories
based on user input.

**Concepts used:**
- Functions
- User input
- f-strings
- Lists and random selection
- Conditional statements

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project folder in PyCharm.
4. Run the main Python file.
